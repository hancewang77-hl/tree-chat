# Page 1 树景背景、前景层次与首屏渐入设计

## 目标

Page 1 使用用户提供的树景 PNG 作为唯一树景背景。现有导航、项目名称、副标题、两个入口按钮和 12 个关键词继续由 DOM 渲染，并保持可访问文本与原有链接行为。

首屏打开时，背景立即出现。前景元素在约 2 秒内完成一次渐入。标题、副标题和入口按钮向上收紧，中央项目名称保持视觉焦点。树景与关键词降低亮度，避免枝干和发光节点压住文字。

Logo 采用仓库现有的 `BrandLogo` 组件和 `public/assets/brand/tree-chat-mark.png` 资源。Page 1 头部恢复附件所示的完整横向结构：左侧标志，右侧 `Tree Chat` 与 `智构树语` 两行字标。生产代码不把带米色画布的参考截图当作 Logo 资源，也不改写标志图形。

## 已批准的视觉方案

### 分层

```text
landing-hero
├─ PNG 背景层                         z-index: 0
├─ 可读性蒙版（hero 伪元素）           z-index: 1
├─ 12 个关键词                         z-index: 3
├─ 导航与进度                          z-index: 1000
└─ 标题、副标题、CTA                   z-index: 2/4
```

PNG 使用 `/assets/landing/page1-tree-background.png`，原始尺寸 1672 × 941，按 Page 1 固定 1080px 高度容器铺满。源文件 SHA-256 为 `D949942FF9641D0868C5646C62C92E5CC339EC94953260EDE92A84C11085A761`，仓库副本必须保持相同哈希。背景层不参与首屏渐入，不改变 `.landing-section` 的高度、滚动吸附或后续 Page 2–9 的背景。

蒙版由现有 Page 1 伪元素承担，采用一层纵向暗化和一层中心径向暗化。中心蒙版在标题所在区域提供稳定对比，边缘蒙版压低树景和发光点。关键词单独降低前景不透明度并保留文字阴影。蒙版不覆盖标题和按钮的 z-index 层。

### 标题与 Logo

`.landing-hero__content` 在现有布局基础上使用 `translateY(-86px)` 将内容组整体上移，数值对应已批准预览在 1080px hero 中的约 9% 位移。该位移不改变区块占位；首屏子元素的 reveal 仍在子节点上运行。标题仍使用现有的 `智构树语 / Tree Chat` DOM，副标题和两个 CTA 不改文字与 href。

头部调用 `<BrandLogo tone="light" />` 的完整变体，移除重复的纯文本 `Tree Chat`。`BrandLogo` 的图片路径、尺寸来源和无障碍规则保持不变；只调整 Landing Page 的调用方式和必要的头部间距，让附件中的横向字标在深色背景上清晰可见。

## 动画与无障碍

首屏动画使用现有 Anime.js 生命周期，但改为共享的分层 reveal：

1. 0–250ms：头部 Logo、进度和导航 CTA 开始出现。
2. 250–900ms：12 个关键词以轻微 stagger 出现。
3. 650–2000ms：eyebrow、标题、副标题和 CTA 完成渐入。

动画只改变 `opacity` 与 `translateY`。关键词的定位变换由外层 reveal 容器承载，避免 Anime.js 覆盖 `dx/dy/anchor` 的 CSS transform。背景图片不延迟、不闪烁，也不参与动画。

`prefers-reduced-motion: reduce` 时，所有前景直接显示，取消延迟和 transform；背景仍立即显示。Page 2–9 不共享 Page 1 的 reveal 状态，也不会因首屏动画而隐藏或改变滚动位置。

## 错误与降级

- PNG URL 保持仓库 public URL。图片缺失时，背景层保留深绿色基底，前景文字与 CTA 仍可读；测试必须发现缺失资源。
- 旧 inline SVG 树景从生产渲染中移除，避免与 PNG 形成双树、错位亮点和重复纹理。12 个关键词保留为唯一的文字数据源。
- Logo 继续使用已存在的 `BrandLogo` 资源。参考截图只用于核对构图，不进入生产 URL。

## 测试与验收

### 单元与组件测试

先新增失败测试，再实现：

- Page 1 输出唯一的 PNG URL、`alt=""` 和非交互背景层。
- 不渲染可见的旧 inline SVG 树景。
- 12 个关键词按名称匹配新坐标和锚点数据。
- 完整 Logo 变体出现在 Landing header，且不重复渲染纯文本品牌名。
- 首屏 reveal 包含 header、progress、关键词层和 hero content，最长完成时间不超过 2000ms。
- reduced-motion 路径直接显示前景，且不等待动画。
- 既有 Page 2–9 scroll/snap 和 Page 9 CTA 契约继续通过。

### 浏览器验收

在 1920 × 1080、1920 × 900 两个视口检查：

- PNG 自然尺寸为 1672 × 941，首帧可见且无水平溢出。
- 标题中心位于现批准的上移位置，副标题和 CTA 不遮挡主枝干。
- 12 个关键词仍落在对应亮点附近，关键词与中心 UI 没有文字重叠。
- 背景和关键词亮度低于中心项目名称与按钮，Logo 保持完整横向字标。
- 约 2 秒后 reveal 完成，Page 2–9 内容仍可滚动到达。
- `prefers-reduced-motion: reduce` 下前景立即可见，且无浏览器错误。

## 取舍记录

考虑过三种实现：继续使用 inline SVG、PNG 与 SVG 叠加、PNG 单一树景。采用 PNG 单一树景，因为用户提供的图像已经包含完整树干、枝条和发光节点；叠加会产生双重树形和坐标冲突。保留现有文字 DOM、BrandLogo 组件和 Page 2–9 结构，降低改动面。
