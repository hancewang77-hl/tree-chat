## 本次交付

Page 2 的 Seed 按钮现在会完成以下流程：

1. 点击后将按钮置为已播种，并更新可读状态文案。
2. 普通动效模式等待种子落土和枝芽生长序列（约 1320ms）完成。
3. 自动以平滑滚动定位到 `#dilemma`（Page 3）的完整 1080px 章节顶边；固定顶部导航叠加在画布上，不改变落点。
4. 章节指示器同步切换到 `03 / 9 · 困境与解法`。
5. `prefers-reduced-motion: reduce` 下不使用平滑滚动，直接定位到 Page 3。

相关实现：

- `src/components/landing/LandingPage.tsx`：Seed 转场、Page 3 ref、章节同步和早期章节定位。
- `src/components/landing/LandingPage.test.tsx`：普通动效、reduced-motion，以及 Page 3 三层树拓扑（节点归属、边端点、连通性和无环性）测试。

## 与原 Plan 的对照

### 已基本满足

- 九章叙事、透明到实色的固定导航、首屏/顶部/页尾 CTA。
- 深森林绿、纸面噪点、银色枝条概念 Logo、Page 3 的树状分支与线性对话对照。
- Page 4–8 使用同一个 R3F 场景和同一个树模型，通过相机关键帧连续移动。
- 晴空蓝渐变、云层、WebGL 静态 fallback、无脚本阅读降级。
- 工作台、API 路由、localStorage 恢复，以及已存在的辅助功能测试保持可用。
- Landing 章节固定为 1920×1080 基准；键盘焦点、ARIA、reduced-motion、44px 最小交互目标和 WebGL 静态降级保留。
- Page 3 已按 Plan 收束为左侧三层无回连树状分支图（1 个根问题、2 个分支、4 个回答节点、6 条唯一父子边）、右上独立的线性对话弊端对照 UI、右下解释文案；对照 UI 不属于树的边集合。
- Page 4–8 已按章节关键帧对齐：完整树居中、枝条左侧、树干右侧、根部下方、树冠居中。

### 与 Plan 仍有差距

- **Page 2：** 点击后说明文案会隐藏并自动进入 Page 3；当前已补充种子→成熟树的 SVG 中间态，但仍不是 Plan 文字中“长成大树”的完整 3D 生长镜头。
- **Page 5：** Plan 文字描述的是枝条左侧上下分区文案；当前采用右侧编辑式信息轨道，四项动作更易读，但仍待关键帧评审决定是否改成字面布局。
- **Page 4 鼠标双图层羽化透视：** Plan 已标注为待定，当前未实装。
- **最终视觉资产：** 原附件中的 Logo 图片未随文档提供；当前 SVG Logo 和程序化低多边形树是可替换的概念资产，不是品牌终稿。本轮没有在缺少品牌关键帧确认的情况下生成或冒充最终资产。
- **Page 9 标准化信息：** 当前只展示已核实的 GitHub、MIT 和产品局限；没有凭空添加备案号、联系人或团队名称。

这些差距主要是视觉关键帧和最终资产评审项，不影响本次要求的现有功能运行与测试结果。
