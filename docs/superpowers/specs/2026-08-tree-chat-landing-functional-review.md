Page 2 的 Seed 按钮现在会完成以下流程：

1. 点击后将按钮置为已播种，并更新可读状态文案。
2. 普通动效模式等待种子落土和枝芽生长序列（约 1320ms）完成。
3. 自动以平滑滚动定位到 `#dilemma`（Page 3），固定顶部导航由文档级 `scroll-padding-top` 避让。

5. `prefers-reduced-motion: reduce` 下不使用平滑滚动，直接定位到 Page 3。

- `src/components/landing/LandingPage.tsx`：Seed 转场、Page 3 ref、章节同步和早期章节定位。

## 与原 Plan 的对照

### 已基本满足

- 九章叙事、透明到实色的固定导航、首屏/顶部/页尾 CTA。
- 深森林绿、纸面噪点、银色枝条概念 Logo、Page 3 的树状分支与线性对话对照。
- Page 4–8 使用同一个 R3F 场景和同一个树模型，通过相机关键帧连续移动。
- 晴空蓝渐变、云层、WebGL 静态 fallback、无脚本阅读降级。
- 工作台、API 路由、localStorage 恢复，以及已存在的辅助功能测试保持可用。
- 375px、844×390px 等视口无水平溢出；键盘焦点、reduced-motion 和 44px 触控目标已覆盖。

### 与 Plan 仍有差距

- **Page 2：** 当前是种子落土后长出 SVG 枝芽，再自动进入 Page 3；还不是 Plan 文字中“长成大树”的完整大树生长镜头，左侧说明文案也没有全部隐藏。
- **Page 3：** 左侧仍保留标题/说明性 caption；Plan 希望除右下说明外尽量不出现解释文字，需后续做一次文案取舍。
- **Page 4–8 构图：** 当前先用统一连续叙事布局。Plan 设想的 Page 5 左侧枝条特写、Page 6 右侧树干、Page 7 底部根部、Page 8 中央树冠等严格左右/上下分区关键帧尚未逐页定稿。
- **Page 4 鼠标双图层羽化透视：** Plan 已标注为待定，当前未实装。
- **最终视觉资产：** 原附件中的 Logo 图片未随文档提供；当前 SVG Logo 和低多边形树是可替换的概念资产，不是品牌终稿。ImageGen 在本次会话不可用，因此没有把临时资产冒充最终定稿。
- **Page 9 标准化信息：** 当前只展示已核实的 GitHub、MIT 和产品局限；没有凭空添加备案号、联系人或团队名称。

这些差距主要是视觉关键帧和最终资产评审项，不影响本次要求的现有功能运行与测试结果。
